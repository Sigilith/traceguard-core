# DEREK

## Governed Runtime

Derek binds.

Responsibilities:
- orchestrating Sigilith
- orchestrating TraceGuard
- invoking AXIOMOS
- executing governed workloads
- producing containment receipts
- publishing telemetry
- enforcing fail-closed execution
- participating in sentinel meshes

Derek executes only after authorization.

Derek does not create:
- structural truth
- evidential truth
- policy authority
