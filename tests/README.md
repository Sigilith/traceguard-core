# THREE-LINEAGE TEST DOCTRINE

Every consequential boundary requires an adversarial test.

Test categories:
- structural
- symbolic
- evidential
- cryptographic
- policy
- authorization
- execution
- infrastructure
- recovery
- concurrency
- telemetry
- reward/proxy manipulation

Required behaviour:

UNKNOWN
  -> QUARANTINE
  -> STOP
  -> PRESERVE EVIDENCE
  -> INVESTIGATE
  -> FIX
  -> RETEST
